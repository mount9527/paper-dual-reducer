# 双降设计：降 AIGC 率 + 篇内重复率

> 本文是工程口径，不是效果承诺。**不预测、不承诺任何平台的检测结果**。
> 所有数字都是本机实测或明确标注「需模型待验」。

## 0. 两个目标必须分开度量

| 目标 | 度量工具 | 是否需要联网/模型 | 能否作为验收 |
|---|---|---|---|
| 降 AIGC 率 | `aigc/detector.py`（`yuchuantian/AIGC_detector_zhv3`） | **需要** transformers + torch + 818MB 权重 | 需要真机；dry-run 的分数不可用 |
| 降篇内重复率 | 引擎 `lib/fingerprint.py`（13 字滚动哈希 + 倒排） | 不需要（纯本地计算） | 可以，离线即可验收 |
| 痕迹诊断（辅助） | `aigc/diag.py`（9 维纯正则） | 不需要 | 可以，作为离线的代理目标 |

**为什么要区分**：重复率是可以离线算准的量；AIGC 率是模型概率，换模型/换版本就变。
把两者混成一个「双降分」会导致无法归因——这是本设计拒绝做的事。

## 1. 度量层

### 1.1 AIGC 概率（考官）

- 模型：`yuchuantian/AIGC_detector_zhv3`（BERT，`chinese-roberta-wwm-ext` 基座），Apache-2.0
- 工程处理：`512 token` 硬上限 → 滑窗 + stride 重叠 + token 级聚合 + 段落/全文打分
- 已知坑：`config.json` 缺 `id2label`，**0/1 谁是 AI 未知** → 必须先 `--calibrate`，否则分数读反而无提示
- 缺依赖时的行为：`--dry-run` 用「文本哈希 → 确定性伪随机」占位。**同一文本每次同值，但与文本质量无关**，
  只能验流程，不能验收

### 1.2 篇内重复率（引擎）

- 13 字滚动哈希，对归一化（去空白、统一全半角）后的字符序列取窗，倒排索引召回共享 ≥2 片段的段落
- 只做**篇内**：作者自己复述自己。不含全网查重（无语料授权，也不做爬取）
- 报告口径：重复占比是「该段中落在重复片段内的字符比例」，不是查重率

### 1.3 9 维痕迹（离线代理目标）

模板套话 / 被动句 / 句长起伏 / 结构对称 / 层层嵌套 / 冒号列举 / 标点节奏 / 口语化 / 破折号。
每次输出 `risk_count`（命中几项）、`risk_score`（加权分）、`level`、`todo`（改写作业清单）、
`style_gate_passed`（语体门禁）。

**离线时它就是唯一可验证的下降目标**：改写前后跑同一次 diag，风险项与分数必须下降，
语体门禁不能从「过」变「未过」。

## 2. 降低手段：把诊断变成动作

### 2.1 提示词注入链（本次新增）

```
diag.py 9 维结论
   → buildHints()  翻译成「改写要求」（每条一句可执行的话）
   → out/aigc-hints.md
   → run.py rewrite --hints <file>
   → build_prompts.py 把【额外要求（来自 AIGC 痕迹诊断）】追加进每一条提示词
   → 模型逐条改写，只产出 edits.jsonl
```

引擎侧对应 `build_prompts.py --hints` 与 `run.py rewrite --hints`（v0.4 起）。

### 2.2 引擎既有算子与文风

- 算子：O1 句长重分布、O2 连接词抑制、O3 语序重排、O4 句法重构、O8 同义替换、O9 引用转述与合并
- 文风档案 `plain`：语序/同义/主被动互换 + 补主语 + 去主观 + 助词化 + 标点连贯
- 九道门禁：实体、主观表述、长度、格式、锁定区、格式锚点、结构、篇级回退

### 2.3 手段与目标的对应

| 痕迹 | 动作 | 影响 |
|---|---|---|
| 模板套话 | 打散「随着…/在…方面/综上所述」，改具体主语 | AIGC 分布；不碰重复率 |
| 句长均齐 / 对称段长 | 短长交替、相邻段句数打散 | AIGC 突发性；可能增加字数 |
| 冒号并列 / 括号套嵌 | 改叙述式，一句一件事 | AIGC 模板度；可读性↑ |
| 破折号超限 / 口语词 | 删减、换书面语 | 过语体门禁（否则判定不合格） |
| 篇内重复片段 | 合并、回指、概括（O9） | 重复率↓；注意不要造成新的模板化 |

## 3. 闭环（DJR-lite）

### 3.1 单轮

```
inspect → diagnose（六维 + 指纹）
        → diag（9 维痕迹）
        → plan（风险加权背包、预算）
        → build_prompts --hints（痕迹要求注入）
        → [模型] 写 edits.jsonl
        → lint（同一套闸门 dry-run，逐条给修法）
        → apply（逐段闸门 → 篇级复检 → 不过整篇回退）
        → reduce/check（diag 复检 + 概率对比）
```

### 3.2 接受准则

| 判据 | 阈值 | 现在能否验 |
|---|---|---|
| 格式零漂移（段落/字符签名） | 必须全空 | ✅ 离线 |
| 实体集合不变 | 必须全空 | ✅ 离线 |
| 锁定区未动 | 必须全空 | ✅ 离线 |
| 语体门禁 | 改写后不得从未过→过（即必须保持/恢复通过） | ✅ 离线 |
| diag 风险项 / 分数 | 下降（或持平且无新增） | ✅ 离线 |
| AIGC 概率 | 下降（具体幅度不作承诺） | ⚠️ 需真机 |
| 篇内重复率 | 不升高 | ✅ 离线 |

### 3.3 多轮与回滚

- 每轮只改一批段落（`--max-tasks`，默认 12），改完复检；不达标就**整篇回退**（引擎内置）
- 回滚粒度：`edits.jsonl` 逐条记录，任何一条可丢弃重来；篇级校验失败时 `apply` 直接回退为原件
- 预算：单段不超过本轮 40%，全篇改写字数不超过可改写量 40%（防止改到面目全非）

## 4. 失败模式与对策

| 失败 | 现象 | 对策 |
|---|---|---|
| 改成了大白话 | 语体门禁 `colloquial.gate_failed` | 门禁硬拦；提示词显式要求书面语 |
| 句子切太碎 | punct 风险升高、读起来断 | 限制「一句不超过 60 字」与「不要用句号切碎片」 |
| 指标降了但意思变了 | 实体/否定/量词守恒可部分兜住，深层语义仍可能漂 | 语义裁判是代理指标（字二元组 + 否定/量词），不做保证；必须人工复核 |
| dry-run 当成结论 | 分数变了但没意义 | 面板黄标 + 工具输出「占位值，不算数」 |
| 去重导致模板化 | 重复降了，但 AIGC 分升 | 先降重、后降 AI；两步分开复检，任一项恶化就回退 |
| 检测器版本漂移 | 历史阈值失效 | 模型版本写进配置并校验，不静默降级 |

## 5. 两类目标的耦合顺序

推荐顺序：**先降重，再降 AI**。

- 降重会合并/概括段落，会改变文本结构；如果先降 AI 再降重，后面这次合并会让刚做的打磨白费
- 反过来，先降重后的文本更稳定，降 AI 的痕迹诊断才有意义
- 每一步都要复检：降重不得提高 AIGC 概率（真机时），降 AI 不得提高重复率（离线可验）

## 7. 未解决与风险

1. **标签方向**：模型卡不声明 `id2label`，校准靠探针 gap ≥ 0.15；探针不灵时必须人工 `--ai-label`
2. **概率的可比性**：换模型版本后历史分数不可比，需要固定版本并记录
3. **单篇验证**：目前只有一篇 862 段真实文档的端到端记录；表格/公式/多级列表覆盖来自该文档构成，
   不是刻意构造的极端样本
4. **合规**：本工具定位是写作辅助，不承诺通过率；改写结果必须由作者复核
